# NPB-cheering-song

スマートフォン向けのNPB応援歌クイズ＆応援歌データベース。Vite / Vanilla JavaScript / HTML / CSS / JSONのみを使用した静的Webアプリです。

## 起動

Node.js 20.19以上、または22.12以上を推奨します。

```sh
npm install
npm run dev
```

ターミナルに表示されたローカルURLを開いてください。

```sh
npm test
npm run test:e2e
npm run build
npm run preview
```

`dist/` が配信用ファイルです。JSONをfetchするため、HTMLを直接ダブルクリックする `file://` ではなくHTTPサーバーで開いてください。ハッシュルーティングなので、静的ホスティングで個別ページのリライトルールは不要です。サブディレクトリへ配信する場合は `npm run build -- --base=/配置先/` を使用してください。

## 収録データ

- 12球団の基本情報。
- 動作確認用の**架空の選手34人**。ヤクルト12人、ほかの11球団は各2人。
- `active: false` の旧データ1件（一覧にもクイズにも出ません）。
- 実際の選手登録情報、歌詞、音源、公式ロゴは収録していません。
- MP3未登録時は「音源準備中」と表示されます。クイズの回答・結果表示はそのまま試せます。

## 実データの追加・差し替え

### 選手と応援歌

`public/data/songs/` 内の球団別JSONを編集します。ヤクルトは `public/data/songs/yakult.json` です。1件が1選手の1曲です。

12球団を別ファイルで管理し、アプリが自動でまとめて読み込みます。各ファイルの `teamId` はファイル名の球団IDと一致させてください。未登録の球団もファイルは残し、中身を `[]` にできます。以前の単一ファイル `public/data/songs.json` は使用しません。

```json
{
  "id": "yakult-player-2026",
  "teamId": "yakult",
  "playerName": "選手名",
  "number": "00",
  "lyrics": "1行目\n2行目",
  "audio": "/audio/yakult/player.mp3",
  "season": 2026,
  "active": true
}
```

- `id` は重複しない文字列、`teamId` は `teams.json` のIDを指定。
- `number` は文字列にしてください。`"00"` → `"0"` → `"1"` の順に表示します。
- ファイルを `public/audio/yakult/player.mp3` に置いた場合、JSONのパスは `/audio/yakult/player.mp3` です。`public` は含めません。
- 改行は `\n`。HTMLタグは解釈せず文字として安全に表示します。
- 旧曲は `active: false` にして残せます。新しい曲は別の `id` で追加してください。
- 同名選手の別曲は、クイズの1セットにつき1人として扱います。全角・半角や空白違いも正規化します。同姓同名の別人を区別したい場合は、将来 `playerId` を追加してください。
- 仮レコードの `demo: true` は実データに差し替える際に削除してください。全activeレコードから削除されるとDEMO表示が消えます。
- 音源が未定なら `audio` を空文字にしても動作します。

### 球団ロゴ

`public/assets/logos/` に `teams.json` が指定するPNGを配置してください。未配置の場合は球団カラーの文字マークを表示します。画像形式やパスを変える場合は `logo` を変更します。

### 背景

`public/assets/images/stadium-crowd-bg.png` を追加すると、トップ画面の球場背景に重ねて表示されます。透過した観客・応援団のシルエット画像を想定しています。画像がなくてもCSSの球場・観客モチーフで成立します。

## 実装ファイル

| ファイル | 役割 |
|---|---|
| `src/main.js` | 起動、ハッシュルーティング、トップ画面 |
| `src/quiz.js` | モード選択、回答、結果UI |
| `src/quizLogic.js` | 重複防止、ランダム出題、集計 |
| `src/database.js` | 球団一覧、背番号順、アコーディオン |
| `src/audioPlayer.js` | 共通再生UI、再生位置、音源切り替え |
| `src/dataLoader.js` | 球団別JSONの取得・統合、データ検証、activeフィルター |
| `src/utils.js` | DOM・歌詞などの共通部品 |
| `src/style.css` | モバイル優先のスタイルとCSS野球ボール |

クイズ開始時に最大10人を確定します。候補が4人未満なら、重複する誤答を作らず選択肢を減らします。「わからない」は不正解とは別に集計します。再挑戦では同じモードで再抽選します。

画面移動・アコーディオン切り替え時には音声を破棄します。ブラウザの戻る・進むに対応しますが、クイズ画面へ戻った場合は新しいセットを開始します。途中経過は保存しません。

## 検証

`npm test` は出題条件、集計、背番号順、データ検証をテストします。ブラウザでの確認状況と手順は `VERIFICATION.md` を参照してください。
